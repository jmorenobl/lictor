# Ideas

Lo que se está pensando para Lictor y todavía no se ha decidido. Una idea no es una decisión ni
está en el roadmap: cuando se decide, pasa a una ADR de `docs/adr/` y su fichero lo dice en la
cabecera, con el número de la ADR.

Cada fichero empieza por su estado y su fecha:

- **En estudio:** se está pensando; puede cambiar entera.
- **Decidida:** pasó a una ADR, que es la que vale.
- **Descartada:** se queda, con el porqué, para no volver a pensarla desde cero.
